# The project follows a modular, multi-tenant architecture:
#
# ┌────────────────────────────────────────────────────────────────────┐
# │                         EXTERNAL INTERFACES                        │
# ├────────────────────────────────────────────────────────────────────┤
# │  Microsoft Teams  │  ConnectWise  │  NinjaOne  │  Entra ID         │
# └────────────────────────────────────────────────────────────────────┘
#                              │
#                              ▼
# ┌────────────────────────────────────────────────────────────────────┐
# │                         API GATEWAY LAYER                          │
# │  (JWT Validation, Rate Limiting, Request Routing)                  │
# └────────────────────────────────────────────────────────────────────┘
#                              │
#                              ▼
# ┌────────────────────────────────────────────────────────────────────┐
# │                      LAMBDA FUNCTION LAYER                         │
# │   ┌──────────────┐  ┌──────────────┐  ┌──────────────┐             │
# │   │ Teams Bot    │  │ Identity     │  │ Ticket       │             │
# │   │ Adapter      │  │ Tools        │  │ Tools        │             │
# │   └──────────────┘  └──────────────┘  └──────────────┘             │
# │   ┌──────────────┐  ┌──────────────┐  ┌──────────────┐             │
# │   │ Triage       │  │ Onboarding   │  │ Portal API   │             │
# │   │ Orchestrator │  │ API          │  │              │             │
# │   └──────────────┘  └──────────────┘  └──────────────┘             │
# └────────────────────────────────────────────────────────────────────┘
#                              │
#                              ▼
# ┌────────────────────────────────────────────────────────────────────┐
# │                      DATA & AI SERVICES                            │
# │   ┌──────────────┐  ┌──────────────┐  ┌──────────────┐             │
# │   │ DynamoDB     │  │ S3           │  │ Bedrock      │             │
# │   │ (15 tables)  │  │ (5 buckets)  │  │ (Agents+KB)  │             │

# │   │ SQS          │  │ Secrets Mgr  │  │ CloudWatch   │             │

# =============================================================================
# MULTI-TENANCY ISOLATION MODEL
# =============================================================================
#
# Resource              Isolation Type    Implementation
# ------------------    --------------    -----------------------------------
# Bedrock Agent         Physical          Separate agent per tenant
# Agent Alias           Physical          Separate alias per tenant
# Action Groups         Physical          Separate groups per tenant
# Secrets               Physical          Separate secret per tenant
# S3 Examples           Logical           tenants/{tenant_id}/ prefix
# S3 KB Docs            Logical           tenants/{tenant_id}/ prefix
# DynamoDB              Logical           tenant_id partition key
# SQS Messages          Logical           Message attributes with tenant_id
#
